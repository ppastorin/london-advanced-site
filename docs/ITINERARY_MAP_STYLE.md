# Itinerary map style

Use `assets/itineraries/it01-wimbledon-route-map.webp` as the graphical reference for future editorial itinerary maps.

## Required characteristics

- Start from a genuine street-and-path basemap. Do not invent neighbourhood boundaries or distort geography to fit a decorative layout.
- Plot every stop from verified coordinates and generate the walking line from pedestrian routing data.
- Draw one restrained, pen-like route in the itinerary green (`#3f6655`) with a narrow paper-coloured casing so it remains legible over roads and park paths.
- Number stops in the order experienced by the reader. A return to an earlier stop should be labelled as a return rather than duplicated as a new destination.
- Use London Advanced’s paper, green, gold and ink palette. Keep labels editorial and sparse; allow the road map to provide geographic context.
- Include the basemap and routing attribution inside the image.
- Export as WebP at a minimum width of 1400 pixels. Preserve a readable road-label size on mobile rather than shrinking a city-wide map into the frame.

## Wimbledon reference

The Wimbledon map uses OpenStreetMap road and path tiles, pedestrian route geometry, an editorial green overlay and five numbered location markers. Its route is:

1. Wimbledon Museum
2. Wimbledon Village Clock Tower
3. Buddhapadipa Temple
4. Wimbledon Windmill
5. Cannizaro Park
6. Return to Wimbledon Village

Google Maps remains the turn-by-turn companion; the editorial map explains the shape and sequence of the day.
